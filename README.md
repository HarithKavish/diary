# Diary

A personal journal, live at [diary.harithkavish.com](https://diary.harithkavish.com).

Part of the HarithKavish ecosystem. See [GOVERNANCE.md](GOVERNANCE.md) for what governs
this repository.

## Running it

Static HTML — no build step, no dependencies. Open [index.html](index.html) directly,
or serve the directory with any static file server.

## Deployment

Deployed to GitHub Pages by [.github/workflows/deploy-pages.yml](.github/workflows/deploy-pages.yml)
on every push to `main`. The custom domain is set via the repository's Pages
configuration and recorded in [CNAME](CNAME).
